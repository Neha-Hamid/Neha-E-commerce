# Neha E-commerce

**Neha E-commerce** is a React-based online clothing store project showcasing Western wear for Men, Women, and Kids.

## Features

- Fully responsive design (desktop and mobile)
- Dynamic product display
- Shopping cart functionality
- Category-based navigation (Men, Women, Kids)
- Styled with CSS & custom components
- Deployed live on Netlify

## Live Demo

Check out the live project here: [Neha E-commerce Live](https://neha-ecommerce.netlify.app)

## Technologies Used

- React.js
- JavaScript (ES6+)
- CSS / Flexbox
- Netlify for deployment
- Git & GitHub for version control
